# Folder Penyimpanan Audio Hadis Arbain An-Nawawiyah

Simpan seluruh 42 berkas rekaman suara hadis (format `.mp3`) di dalam folder ini dengan pola penamaan:

- `hadis-01.mp3` -> Hadis 1: Amal Bergantung pada Niat
- `hadis-02.mp3` -> Hadis 2: Pengertian Islam, Iman, dan Ihsan
- `hadis-03.mp3` -> Hadis 3: Rukun Islam Sebagai Fondasi Agama
- `...`
- `hadis-42.mp3` -> Hadis 42: Luasnya Ampunan Allah

Semua berkas di folder ini dapat diakses secara publik via URL: `/audio/hadis/hadis-XX.mp3` dan otomatis di-cache oleh Service Worker untuk mode offline.
